# Procedural GLB catalog

- `crates/gen_assets` owns mesh construction, GLB serialization, catalog validation, and its CLI. It consumes canonical dimensions, collider contracts, paths, variants, and semantic names from `shared::art`.
- Output is texture-free glTF 2.0 binary: meters, Y-up, forward -Z, ground pivot at Y=0, flat normals, linear vertex colors, and high-roughness PBR materials.
- Catalog generation is byte-for-byte deterministic. Stable scene, node, mesh, material, socket, and animation names are runtime API.
- Keep the project-owned modeling vocabulary small and use explicit mesh helpers instead of an external procedural-modeling framework.
- `--check` compares existing files with canonical generated bytes and never writes.

Generate and verify:

```sh
cargo run -p gen_assets -- --out-dir crates/main/assets/models
cargo test -p gen_assets
cargo run -p gen_assets -- --check --out-dir crates/main/assets/models
```
