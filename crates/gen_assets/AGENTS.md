# Purpose

Deterministic procedural low-poly GLB catalog generator.

# Ownership

- Owns `crates/gen_assets/`, including mesh construction, GLB serialization, catalog validation, and its CLI.
- Consumes canonical names, dimensions, and collider contracts from `shared::art`.

# Local Contracts

- Output is texture-free glTF 2.0 binary: metres, Y-up, forward -Z, ground pivot at Y=0, flat normals, linear vertex colors, and high-roughness PBR materials.
- Catalog generation must be byte-for-byte deterministic.
- `--check` validates that existing output exactly matches canonical generated bytes and never writes files.

# Work Guidance

- Keep the modeling vocabulary project-owned and small; prefer explicit mesh helpers over external procedural-modeling frameworks.
- Stable semantic scene, node, mesh, material, socket, and animation names are runtime API.

# Verification

- `cargo test -p gen_assets`
- `cargo run -p gen_assets -- --check --out-dir crates/main/assets/models`
